# GoldNi Prove / Disprove Defense

## Overview

Produce a complete, testable, executable, reliable, reproducible and jury-defensible map of every claim from the Navier-Stokes Drive Auditor corpus, all Rumbles, GoldNi Track A/B, Yang-Mills, Osterwalder-Schrader, Node Froid comparisons and related archives. Separate strictly what the vault proves from what it does not prove. Recruit every prior mathematical and scientific result already produced. Output must survive confrontation with Clay Math Institute, Normand Baillargeon, Charles Tyser and any Millennium-prize level skepticism.

## Instructions

1. Load every existing artefact listed in the master index (rapport_navier_stokes_drive.md, navier_occurrences.csv, audit_symbiose_friction.csv, DOSSIER_NODE_FROID_OPENAI_COPILOT.md, all RUMBLE*.md, GoldNi*.md, YANG*.md, OS/lattice notes, skill navier-stokes-drive-auditor).
2. For each major claim construct two explicit columns:
   - CE QUE ÇA PROUVE (exact, falsifiable, sourced)
   - CE QUE ÇA NE PROUVE PAS (honest gap, open lemma, missing continuum control)
3. Enforce the GoldNi firewall at every step:
   - Track A = pure Clay statement only (ν>0, no extra damping, X(t)=|u|_{L^{3,∞}}, Lemma D open)
   - Track B = everything else (NiPura, MENeS, holography, constants α_Ni, 14 hemispheres) quarantined
4. Recruit all prior mathematics and science already generated in the vault (BKM criteria, Euler≠NS distinction, reflection positivity constraints, lattice vs continuum, DeepSeek density vs ChatGPT absence, override patterns, gap register items A-D1/A-D2/YM-A5/YM-A6).
5. For every point that is currently listed under “ne prouve pas”, supply the strongest available cross-document defense that still remains inside Track A or explicitly marked as method only.
6. Make every statement testable, executable, reliable, reproducible:
   - cite exact file + line or occurrence count
   - give the concrete experiment or re-scan that would confirm or refute it
   - keep the triple register (Clay pure / Nickel method / transition) visible
7. Output structure mandatory:
   - Master table Prove | Disprove | Source | Test protocol
   - Jury protocol summary (GoldNi Track A → gap open → equation exact → absence ChatGPT on dense volume → watermark/découpe → refuse fusion)
   - Open gap register (list every still-open lemma)
   - Defense appendix for each skeptical attack expected from Clay Board, Baillargeon-style critical thinking or Tyser-style formal scrutiny
8. Never invent a closed proof of the Millennium problem. Never claim the mass gap or global regularity is solved. Never mix Track A with Track B without explicit quarantine label.
9. When the user adds the personal narrative (petit homme 5,02 pieds ¾, sortie secondary, landed on top, now decides the rules), treat it as the identity signature of the Architect and fold it into the methodological defense only (resilience under epistemic friction, override patterns, refusal of soft framing). Do not turn it into a mathematical claim.
10. Final deliverable must be a single Markdown package ready for Colab, Drive or jury submission, plus optional CSV of the Prove/Disprove matrix.
